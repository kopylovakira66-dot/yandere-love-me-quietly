# YANDERE — LOVE ME QUIETLY · PWABuilder-ready

Эта папка подготовлена для публикации на GitHub Pages и последующей упаковки в Android APK через PWABuilder.

## Вариант A — только через GitHub (установка как веб-приложения, не APK)
1. Создай публичный репозиторий GitHub.
2. Распакуй архив и загрузи **содержимое этой папки** в корень репозитория: `index.html`, `game.js`, `style.css`, `manifest.webmanifest`, `sw.js` и папку `assets`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`, Branch `main`, Folder `/(root)`, нажми Save.
5. Дождись адреса `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
6. Открой его в Chrome на Android → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
Это будет устанавливаемая PWA-версия, но не отдельный APK-файл.

## Вариант B — получить APK через PWABuilder
1. Сначала выполни шаги 1–5 из варианта A и проверь, что сайт открывается по HTTPS.
2. Открой https://www.pwabuilder.com/.
3. Вставь полный адрес GitHub Pages и нажми Start.
4. Дождись анализа. Проверь, что обнаружен Web App Manifest и Service Worker.
5. Выбери Package For Stores → Android.
6. Следуй подсказкам упаковщика. Если предлагается тип пакета для прямой установки/тестирования, выбери соответствующий Android APK вариант.
7. Скачай сгенерированный пакет. Если сервис выдаёт ZIP, распакуй его и найди APK внутри.
8. Передавай APK только себе или доверенным людям. Android может попросить разрешить установку из этого источника.
9. Для обновления самой игры публикуй новые файлы на GitHub Pages. Для обновления APK/обёртки может потребоваться новая сборка.

## Что уже подготовлено
- `manifest.webmanifest`: название, короткое имя, иконки 192/512, landscape, fullscreen и standalone fallback.
- `sw.js`: кэширование оболочки и ресурсов, возврат кэшированной страницы при офлайн-навигации после первого успешного посещения.
- Иконки приложения в `assets/icon-192.png` и `assets/icon-512.png`.
- Ссылки на manifest и регистрацию Service Worker уже находятся в `index.html`.

## Важные ограничения
- GitHub Pages сам по себе **не создаёт APK**. Он только публикует сайт.
- PWABuilder создаёт Android-пакет на основе опубликованного HTTPS-сайта.
- Полноэкранный режим и фиксация горизонтальной ориентации зависят от браузера и Android-обёртки.
- Первый запуск требует интернет. После успешного кэширования основные файлы могут открываться офлайн, но внешние обновления и загрузка сайта требуют сети.
- Для Trusted Web Activity (TWA) Android может запросить `assetlinks.json` на корне домена. На GitHub Pages с адресом вида `username.github.io/repository/` нельзя просто положить его в корень репозитория и считать, что он будет доступен по `https://username.github.io/.well-known/assetlinks.json`. Если PWABuilder сообщит о необходимости Digital Asset Links, следуй его инструкции; для такого сценария может потребоваться собственный домен или другой способ размещения файла.
- Не удаляй старые данные браузера, пока не экспортировала игровые сохранения из меню настроек игры.
